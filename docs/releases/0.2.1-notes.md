# Pocket TTS Studio lite 0.2.1

Released **2026-11-04**.

## Fixes

- Fixed a crash when minimizing or restoring the application.
- Fixed cancellation errors in model-removal and voice-profile overwrite dialogs.
- Improved error handling when a speech preview fails or the application is
  closed during preview generation.

## Installation

Download `PocketTTSStudioLite-0.2.1-win-x64-Setup.exe` and its matching `.sha256`
file from [GitHub Releases](https://github.com/MartinRoskoEU/Pocket-TTS-Studio-Lite/releases/tag/v0.2.1).
Install over the existing version to preserve private models, settings and data.

The installer is unsigned and installs for the current user. Models download
separately. See [requirements and installation](../windows-installer.md) and
[the changelog](../../CHANGELOG.md).
