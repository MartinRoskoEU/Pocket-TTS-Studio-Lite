# Pocket TTS Studio lite 0.2.2

Released **2026-11-12**.

- Add **Repair runtime** in Settings to restore a missing executable from its exact
  verified official release, preserving the saved model selection.
- Check for newer application releases at startup and through Settings, with
  **View release** opening the published release page.
- Improve installer and uninstaller responsiveness, restore **Cancel** during file
  copying, and align the **Finish** button.
- Clean up cancelled installations and restore backed-up original files when an
  update is cancelled, preserving existing application data.
- Use the stable **PocketTTSStudioLite-Setup.exe** installer filename for future releases.

Download [PocketTTSStudioLite-Setup.exe](https://github.com/MartinRoskoEU/Pocket-TTS-Studio-Lite/releases/download/v0.2.2/PocketTTSStudioLite-Setup.exe)
and its [SHA-256 checksum](https://github.com/MartinRoskoEU/Pocket-TTS-Studio-Lite/releases/download/v0.2.2/PocketTTSStudioLite-Setup.exe.sha256).
Install over the existing version to retain private models and settings.

The installer is unsigned and installs for the current Windows user. Models are
available as separate downloads through Settings.
See [requirements and installation](https://github.com/MartinRoskoEU/Pocket-TTS-Studio-Lite/blob/v0.2.2/docs/windows-installer.md).
