# Pocket TTS Studio lite 0.2.0

Released **2026-11-03**.

## What's new

- Update supported installed voice-cloning models while keeping the selected model.
- Check for model and runtime updates with one action in Settings. Confirm each
  update before downloading it.
- Automatically retire verified superseded model files and inactive downloaded
  runtimes after successful updates. The active and bundled runtimes are preserved.
- Recover recorded interrupted downloads and pending cleanup.
- Improved per-user reinstall and uninstall, including removal of completed
  maintenance records and empty application directories.
- Stable Voice Cloning page positioning when previews and notifications appear,
  using native WinUI scroll anchoring.

## Installation

Use `PocketTTSStudioLite-0.2.0-win-x64-Setup.exe` and its matching `.sha256` file from
[GitHub Releases](https://github.com/MartinRoskoEU/Pocket-TTS-Studio-Lite/releases).
The installer is unsigned and installs for the current user. It includes .NET,
Windows App SDK and the official Pocket TTS runtime; models download separately.

Install over the existing version to preserve private data. Uninstall retains
private data by default and offers removal of verified application-managed data.
External profiles, unknown files and shared caches are preserved. Uninventoried
extras from 0.1.0 are also preserved; the uninstaller does not sweep unknown files.

Requires Windows x64 with AVX2/FMA and Media Foundation. See
[requirements and installation](https://github.com/MartinRoskoEU/Pocket-TTS-Studio-Lite/blob/v0.2.0/docs/windows-installer.md#installation-and-prerequisites).
