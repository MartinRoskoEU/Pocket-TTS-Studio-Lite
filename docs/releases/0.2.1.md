# 0.2.1 verification record

Release date: **2026-11-04**. See the [public release notes](0.2.1-notes.md)
for user-facing fixes and installation instructions.

## Findings and scope

- The pre-fix isolated window reproduced the minimization crash: WinUI reported
  a negative caption-button inset (-14), which caused `GridLength` to throw.
- Cancelling a dialog with the pre-fix native `Hide` delegate reproduced
  `InvalidCastException`, propagated by cancellation as `AggregateException`.
  Both model-removal and overwrite-confirmation handlers used this pattern.
- Preview generation and its closing handler awaited a task without catching
  unexpected task failures. The updated handlers were checked with faulted tasks
  and both successful and unsuccessful simulated runtime cleanup.
- The final tested method bodies and cancellation blocks match production sources.
  The isolated harness creates real WinUI windows/dialogs but uses synthetic
  generation tasks and simulated cleanup rather than model inference.
