## Final implementation notes

Installer preparation reuses the already loaded bootstrap DLL and retains its
hash verification. Completed uninstall recovery state is queued last in the
checked native deletion batch. Success releases the operation lock and directory
pins before Inno removes its bootstrap and 131 registered empty-directory paths.
Failure preserves recovery state and exits before Inno's removal pass. Unknown
files, shared caches, external profiles and uninventoried legacy extras remain
preserved. See [installer maintenance](../installer-maintenance.md).

Stable Voice Cloning content opts into `CanBeScrollAnchor`. Native WinUI maintains
a visible candidate during layout changes; there is no manual offset restoration,
focus redirection or focus-scroll suppression. The isolated live WinUI probe
completed six anchored scenarios and two controls: five kept the anchor at its
exact viewport position; one reached the native scroll-range limit. Evidence is
under `artifacts/scroll-diagnostics/`. This probe uses inert audio controls and
does not exercise actual model generation or media playback.
