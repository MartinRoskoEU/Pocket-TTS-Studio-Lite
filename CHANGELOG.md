## [0.1.0] - 2026-10-29

### Added

- Prepare the first per-user x64 Inno Setup installer for 0.1.0, with self-contained
  .NET/Windows App SDK, the mandatory hash-verified official Rust runtime, existing
  branding, Start Menu shortcuts, stable upgrade identity, and Windows uninstall
  registration. Validate AVX2/FMA and Windows media prerequisites; use official
  Windows Media Feature Pack servicing only when needed. Preserve private data on
  upgrades and offer explicitly confirmed, path-guarded private-data cleanup during
  interactive uninstall. Include dependency notices and MPL source archives; do not
  bundle/download model weights or run installation on the development PC.
- Establish MSBuild `Directory.Build.props` as the release-version source (0.1.0).
  Derive assembly/package manifests, window/title-bar version, HTTP User-Agent, and
  Inno version/filename from it. Document build, prerequisites, upgrade/uninstall,
  unsigned distribution, and clean-machine validation requirements.
